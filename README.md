# 🛒 ShopBase Database Project

A relational database design and implementation for an e-commerce platform built with **Microsoft SQL Server (SSMS)**.

> 📌 **Project Status:** Under Active Development 🚀

---

## 📖 Overview
This project models the core backend database structure for a retail/e-commerce system. It covers customer management, product cataloging, order tracking, and relational data integrity.

---

## 🗄️ Database Schema & Entities
The database includes the following key tables and relations:

- **Customers:** Customer credentials, addresses, and contact details.
- **Products:** Product catalog, categories, pricing, and stock status.
- **Orders:** Transaction records, order status, and customer references.
- **OrderDetails:** Itemized breakdown of ordered products and quantities.

*(More tables, views, and stored procedures will be added as development progresses.)*

---

## 🛠️ Tech Stack & Tools
- **RDBMS:** Microsoft SQL Server (MS SQL)
- **IDE / Management Tool:** SQL Server Management Studio (SSMS)
- **Language:** T-SQL (DDL & DML)

---

## 🚀 Getting Started / Setup
To restore and execute this database locally:

1. Clone or download this repository.
2. Open **SQL Server Management Studio (SSMS)** and connect to your instance.
3. Open the `ShopBase-Database-Project.sql` file.
4. Execute the script (`F5`) to create the database schema, tables, and seed data.
